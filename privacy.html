Privacy Policy – Gmail Mcp

Last updated: 16 October 2026

"Gmail Mcp" is a personal automation tool built and used only by Alan Chris Antony (alanchrissantony@gmail.com). It is not offered to the public and has no other users.

What data it accesses

With the account owner's consent through Google OAuth, the tool accesses the owner's own Gmail account to:

  • send job-application emails and a run-summary report written by the owner;
  • read the owner's sent mail to avoid sending duplicate applications;
  • create drafts and apply labels to messages it sends.

How data is used and stored

Data is processed only on the owner's own computer. Google OAuth tokens and a small local log of sent applications are stored locally on that computer. No Gmail data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
